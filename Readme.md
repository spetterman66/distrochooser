# DistroChooser 🐧
DistroChooser allows you to find the perfect Linux distribution for **you**, depending on your skill level.
Built with vanilla JavaScript, HTML and Bootstrap 5.
## Changelog
### 2025-10-22
- Updated Bootstrap to latest version via CDN in all HTML files.
- Rely more on Bootstrap's built-in classes for styling and layout.
- What's a nice UI without some shadows? Added shadow to main content containers.
- Placeholder values and tooltips added to buttons for better user experience.
